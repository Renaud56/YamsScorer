# YamsScorer
Yams scorer app

## Mode de test

Ouvrir `index.html?test=1` dans le navigateur pour charger dix parties de démonstration, sans serveur. Le fixture est intégré à la page et n'est utilisé qu'avec ce paramètre. Le mode test n'écrit pas dans le stockage local et désactive import et synchronisation.

## Installation Android

Le site est une PWA servie par GitHub Pages à l'adresse HTTPS `https://renaud56.github.io/YamsScorer/`. Après publication des fichiers, ouvrir cette adresse dans Chrome sur Android, puis choisir **Installer l'application** dans le menu du navigateur. Le cache hors ligne est rempli à la première visite en ligne ; les parties locales restent disponibles hors ligne, mais la synchronisation Google Drive nécessite une connexion Internet. Les fichiers de l'application sont servis sous le chemin `/YamsScorer/` et les données locales restent rattachées à cette origine.
